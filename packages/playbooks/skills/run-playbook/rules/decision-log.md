# 判断の記録

長い作業、利用者が離れている間の作業、手順を組んだ作業、別のセッションに渡す作業では、分かれ道の判断を記録する。

- 置き場は、引き継ぎのメモ（リポジトリの主の作業ツリーの `.ai-out/<主題>/YYYY-MM-DD-<主題>-handoff.md`）の「決まったこと」のセクションにする。`.ai-out/` の直下には置かない。
  - メモがなければ作る。セクションは、スキル run-session の playbook delegate-work の、引き継ぎのメモを作る手順に並べたものにする。
  - スキル run-session が無ければ、「決まったこと」のセクションだけのメモにする。
- 1 つの判断を 1 行にし、時刻、判断、理由、根拠の在りかを書く。根拠は文章ではなく、コミット、`<path>:<行>`、pull request で指す。
- 記録するのは、次のとき。
  - 2 つの案から選んだとき。判断の 3 段の 1 段目で推奨の案に決めたときを含む。
  - 確認の結果が出たとき。
  - 方針を変えたか、変更を戻したとき。
  - 先へ進めないとき。
  - 外部の待ちの上限を超えて進めたとき。
  - 尋ねた論点の答えを受けたとき。「返事待ち」から消し、ここに 1 行を足す。
- 追記だけにする。誤った行は書き換えず、訂正の行を足す。
