# ワーカーとサブエージェント

- サブエージェントは、セッションの中から起動し、結果を呼んだ側へ返して終わる。
  - 数は、作業に要る分だけにする。1 つで足りる作業を分けない。サブエージェントに、さらにサブエージェントを起動させない。取り消せない操作をさせない。
  - 返した結論のうち、返答に使う部分は自分で確認する。
- ワーカーは、別のセッションを立ち上げる手段で起動する、独立したセッションである。親のセッションが止まっても、渡された作業を自分の完了の条件まで進める。
  - 指示と結果は、引き継ぎのメモとリポジトリの状態（ブランチ、コミット、pull request）で受け渡す。ワーカーは、作業の中でサブエージェントを使ってよい。
  - 事前の権限は、委任のセクションを通してワーカーにだけ渡す。サブエージェントには渡さない。ワーカーは、受けた範囲を広げない。
  - ワーカーは、判断の 3 段の 2 段目の論点を、親のセッションに、完了の通知と同じ手段で尋ねる。親は、委任の範囲と 1 段目で答えられるものだけに答え、残りを利用者に尋ねる。
- 別のセッションを立ち上げる手段、端末を読む手段、完了を知らせる手段の具体は、利用者の context か個人の構成に従う。
