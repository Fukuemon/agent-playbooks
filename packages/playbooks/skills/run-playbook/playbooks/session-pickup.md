# session-pickup

**担当:** 前の会話や別のエージェントの作業を、続きから再開する。前の記録を読み、済んだ作業をやり直さない。

1. 前の記録を探す。`.ai-out/` の再開のメモと判断の記録、作業用のブランチ、pull request とそのコメント、利用者が渡した会話。長い記録は、サブエージェントに読ませて、時系列の要点だけを受け取る。
2. 今の状態を組み立てる。ブランチと worktree、取り込み先との差分（`git log`、`git diff`）、残っている作業、決まった判断。前の記録を、判断の元として扱う。
3. 済んだことと残っていることを比べ、再開する場所を決める。済んだ作業の再現や確かめを、最初からやり直さない。
4. 前の作業が「済んだ」とした主張のうち、残りの作業が頼るものは、本物で確かめる。prove-it-works を読む。前の自己申告は、確かめたことにならない。
5. 残りの作業に合う playbook を選び直し、その playbook に移る。

**返答に書くこと:** 前の作業がどこで止まっていたか、引き継いだものとやり直したもの、再開した場所、移った playbook。
