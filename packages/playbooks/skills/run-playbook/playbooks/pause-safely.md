# pause-safely

**担当:** 作業を、ほかのエージェントが続きから再開できる形で止める。明示の中断、席を外すとき、会話の要約が近いとき、取り消せない操作の前で止まるときに使う。  
「続けて」「止まらずに」と言われているときは、明示の中断としては止まらない。ただし、取り消せない操作と、利用者だけが決められる判断の前では、言われていても止まる。

1. 安全な区切りで止まる。今の手順を終えるか、手前に戻す。新しく始めない。起動中のサブエージェントを止める。
2. 止まるために、取り消せない操作をしない。push と pull request の作成は、既にしているもの以外はしない。
3. 作業を失わないようにする。作業用のブランチで、未コミットの変更を 1 つのコミットにまとめる。type と題は、CONTRIBUTING.md とスキル write-commit に従い、作業の途中であることを題か本文に書く。作業ツリーがビルドやテストを通らない状態なら、そのことをコミットの本文に 1 行で書く。
4. 再開のメモを、リポジトリの `.ai-out/` に書く。ファイル名は `YYYY-MM-DD-<主題>-resume.md` にする。書くのは、目的、していたこと、進み具合と確かめたこと、今の状態、次の手順、関係するファイル、注意点。判断の記録があれば、写さずに場所を指す。

**返答に書くこと:** 作業の中のどこにいるか、ファイルに残したものと残していないもの、作ったコミットと作業ツリーの状態、再開したときの最初の操作。最後の報告ではなく、中断であると書く。
