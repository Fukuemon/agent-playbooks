# fix-root-causes

症状を隠さず、再現してから原因を直す。

- 再現してから直す。再現しない不具合への修正は、推測である。
- 「なぜ」を重ね、変えれば症状が消える最も根の位置まで進む。
- 症状を消すだけの分岐、再試行、握りつぶしを足さない。足したくなったら、その理由を書き出し、原因の調べ直しに戻る。
- 1 か所を直したら、同じ形の箇所を探す。
- 説明に段落 1 つ分のコメントが要る回避策は、原因に届いていない。
- CI の失敗を、原因を分けずに再実行で通さない。

## 当てはまらない例

- 原因が外部のサービスやパッケージにあり、このリポジトリでは直せない。回避策を入れるときは、原因の在りかと、回避策を外す条件を書く。
