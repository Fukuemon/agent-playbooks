# prove-it-works

終えたと言う前に、本物で動かして確認する。

- 利用者が使うのと同じ画面、コマンド、入力で動かす。画面は `context/testing/e2e.md` と `context/testing/evidence.md` の手順で、画面が無ければ `context/testing.md` の Runtime Requirements の手順で動かす。手順が書かれていなければ、verification-setup で作ることを返答で提案する。代わりの指標（ビルドが通った、型のチェックが通った、単体テストが通った、サブエージェントが終えたと言った）は、確認したことにならない。
- 確認した方法と結果を、返答に書く。出力は要約せずに貼る。
- 確認できなかったときは、終えたと言わない。何を確認できなかったか、なぜかを書く。
- 「結論が出ない」は合格ではない。

## 当てはまらない例

- 文書だけの変更で、文書のチェックを通した。動かす対象がない。
