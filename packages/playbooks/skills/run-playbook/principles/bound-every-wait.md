# bound-every-wait

外部の待ちには、待ち始める前に上限を決める。

- 外部の待ちは、自分では終わらせられない待ちを指す。自動のレビュー、CI、終わらない入力やコマンド、ほかのセッションや利用者の返事が当たる。
- 待ち始める前に、上限の時間と、状態を見る間隔を決める。利用者の context か引き継ぎのメモに上限があれば、それに従う。
- 状態は、完了を判定できる値（状態の値、終了コード、対象のコミット）で見る。表示の文言や出力の量で判定しない。
- 待つ間に進められる作業があれば進める。
- 上限を超えたら、次のどちらかを選ぶ。
  - 代わりの根拠で進める。自動のレビューが来なければ、自分で差分を読み直してレビューする。
  - 止まる。代わりの根拠がなく、待つ相手の結果がないと先へ進めないとき。
- 待たずに進めたことを記録する。何をどれだけ待ち、何で代えたかを、引き継ぎのメモの「決まったこと」と、関係する pull request に 1 行で書く。

## 当てはまらない例

- 利用者の承認や判断の待ち。上限を超えても、代わりの根拠で進めない。尋ねたことを引き継ぎのメモの「返事待ち」に残し、ほかの作業へ移るか止まる。
